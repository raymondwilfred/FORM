# FORM

Interactive User Registration Form
A comprehensive HTML5 and CSS3 application form designed to capture multi-format user data with clean UI separation.

Features Implemented:

Diverse Input Handling: Integrated text inputs, date pickers, radio buttons (for gender), and checkboxes (for multi-select skills).

Semantic Structure: Used proper <label> and id associations to ensure accessibility and better click-targets.

Form Validation Ready: Built with specific input types (email, tel) to leverage native browser validation.

Responsive Layout: Designed the form container with a high-contrast theme for clear readability and focus.
